Проект: логистическая регрессия для оценки вероятности возврата кредитов

Датасет: Germany Credit

Описание: Проект реализован без готовых решений ML-библиотек, используя только алгебру, матанализ и мат.статистику. Для помощи в вычислениях и обработки данных были использованы библиотеки: numpy, pandas, random. В задачи входило:

логистическая регрессия(сигмоида от линейной комбинации)
стохастический градиентный спуск на основе функции потерь LogLoss
использование метрик для оценки качества модели
обработка данных с one-hot encoding, порядковым кодированием, масштабированием на основе медианы и межквартильного размаха(RobustScaler).
Предусмотрено логирование стадий обучения модели в файл с логами(каждые 100 эпох). Модель выдает вероятность возврата кредита(0-1), вместо бинарной классификации, поэтому может использоваться в процессах принятия решений о выдаче/невыдаче на основе настраиваемого порога.

Запуск: python main.py
